# 🧍 My Buddy

A tiny Windows desktop companion that sits on your taskbar, reminds you to drink water, greets you when you open your laptop, and dances to music.

Built with Electron, Node.js, JavaScript, and custom character animations.

## ✨ Features

- 💧 Water reminders with interactive responses
- 👋 Greetings on startup, unlock, and wake from sleep
- 🎵 Music detection with dancing animations
- 🪑 Sits on the taskbar
- 🖱️ Transparent, click-through window
- 🚀 Automatic startup with Windows

## 🛠️ Tech Stack

- Electron
- Node.js
- JavaScript
- HTML & CSS

## 🚀 Getting Started

**Requirements:** Windows 10/11 and Node.js.

```bash
git clone https://github.com/Karthik-ctrl25/my-buddy.git
cd my-buddy
